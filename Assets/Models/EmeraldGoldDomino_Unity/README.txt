EMERALD GOLD DOMINO FOR UNITY URP

1. Copy entire EmeraldGoldDomino_Unity folder into Assets.
2. Select OBJ, Model > Normals = Import.
3. Run Tools > Domino > Create Emerald Gold Prefab.
4. Open generated prefab; inspect material mapping and adjust if needed.
5. For existing gameplay prefab, replace ONLY visual mesh child, preserving existing collider, Rigidbody and Domino scripts.

Dimensions X=.1 thickness Y=1 height Z=.4 width; centered origin.
Gold trim is real geometry, not another prefab.
For visual reference: use a studio reflection probe/HDR environment and suitable lights.
